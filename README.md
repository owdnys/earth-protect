# 地球守护计划 · EARTHKEEPER

一款可离线运行的中文地球策略小游戏。旋转地球、选择行动区域、实施生态干预，观察气候与生态指标变化；目标是在 20 年结束时把地球生命力保持在 **75 分及以上**。

## 立即开始

**双击本文件夹的 `index.html`**，即可在 Chrome 或 Edge 中游玩。无需安装、登录、服务器或联网。

`index.html` 是**单文件自包含**的：样式、游戏逻辑、世界地图数据和图标全部内联在这一个文件里，不再依赖任何外部文件。因此它可以直接单独打开、单独部署，不会因为缺少配套文件而白屏。

- 鼠标拖动地球旋转、滚轮缩放，点击地球选择目标区域；区域行动效果提高 20%。手机上可触控旋转和点击。
- 选择「植树 / 清洁能源 / 海洋修复 / 绿色城市」，选择力度，点击执行。力度越大，效果与资源消耗越高。
- 「推进一年」会获得 18 资源，地球也会依模拟规则自然变化。行动记录、指标、游戏进度实时更新，刷新后自动续玩。
- 第 20 次推进会结算；「重新开始」可清除当前进度。

> 游戏数值属于**简化的策略模拟模型**，不是真实世界预测。

## 上传到 GitHub → Cloudflare Pages

本文件夹就是**静态网站根目录**，不用 npm、不用构建、没有后端。

需要上传的文件只有三个：

| 文件 | 作用 | 是否必需 |
| --- | --- | --- |
| `index.html` | 游戏本体（单文件自包含） | **必需** |
| `_headers` | Cloudflare Pages 安全响应头 | 可选 |
| `README.md` | 本说明文档 | 可选 |

把这三个文件直接放在**仓库根目录**（`index.html` 必须在根目录，不要再套一层文件夹），提交推送即可。

Cloudflare Pages 设置：**Framework preset = None**、**Build command 留空**、**Build output directory = `.`**。

> 注意：早先的版本把地球库拆在 `assets/` 子文件夹里。如果上传时漏掉该文件夹，服务器会拿网页去充当 JS 文件返回，浏览器因 MIME 类型不符而拒绝执行，页面就会提示"无法启动地球"。现在已改为单文件，**不会再出现这个问题**。如果你的仓库里还留着旧的 `assets/` 文件夹或 `app.js`、`style.css`，可以删掉，新版本不再需要。

## 兼容性

地球使用 **Canvas 2D** 绘制（正交投影），**不依赖 WebGL**，因此在较新的 Chrome 与 Edge 上均可正常运行，包括禁用硬件加速或显卡驱动异常的环境。仅在浏览器完全不支持 Canvas 时才会显示降级提示，此时游戏的其他功能仍可正常使用。

## 第三方声明

世界陆地轮廓数据来自 Natural Earth（公有领域），经 world-atlas / topojson-client 转换后内联。Three.js、d3-geo、d3-array 已在本次改造中移除，不再随游戏分发。地理数据经过简化，不适用于法律边界解释。
